建議討論順序：

1. `01_Excel與PDF系統化工作台.html`
   - 先確認既有 Excel 欄位、PDF 簽呈內容與來源追溯，不要直接跳成全新系統。
2. `02_案例流程_中華電信電力費調整.html`
   - 再確認紅線流程是否符合真實作業。
3. `03_系統資料流整合模擬.html`
   - 再看系統如何串 Case、合約、付款、預算、核銷、發票與稽核。
4. `04` 到 `07` 的角色畫面
   - 只確認角色責任和操作想像，不先討論 UI 細節。
5. `docs/業主訪談問題清單_v2.5.md`
   - 照清單問業主，收斂規則與代表案例。
6. `docs/欄位確認問題與建議_v3.0.md`
   - 這份是我方建議版：哪些直接由系統設計決定，哪些才需要業主判斷。

PM 提醒：

- 這包不是正式 UI 定稿。
- 這包的主要目的，是確認業務流程與規則。
- 這包現在的方向是「把既有 Excel / PDF 簽呈內容系統化」，不是從零做一套新系統。
- 欄位討論不要問業主要不要拆 DB 表；我們先給建議，只請業主確認來源、意義、責任與例外。
