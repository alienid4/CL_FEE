這份用來判斷是否可以進入第一階段開發。資料先收齊到可驗證、可對照、可追溯，再開始寫 MVP Code。

開發前必備文件

第一批先拿最新版、近三個月樣本、異常案例樣本。

必備 近三個月 保留原檔
資料包 要提供什麼 建議提供者 用途 缺少影響
Excel 主來源 費用項目整合23.xlsx、次月預計上簽項目.xlsx、架構部續約合約進度.xlsx、年度預算 / 專案追蹤相關 Excel。 助理 建立 Case、費用、合約、預算、上簽與來源追溯。 無法確認欄位、主檔、狀態與匯入規則。
PDF 簽呈樣本 例行付款、專案付款、續約、計畫外採購、漲價補差、預算保留 / 轉用各 2 至 3 份。 助理 / 承辦 確認 PDF 需擷取的案名、金額、期間、簽呈編號、頁碼與來源。 PDF 只能當附件，無法做簽呈內容追溯。
預算資料 去年編列今年、今年核定、明年提報、預算保留申請、凍結取消、計畫外採購、漲價補差資料。 主管 / 助理 建立預算流向、年度使用統計、凍結取消與計畫外採購清單。 主管看不到錢從哪來、用到哪裡、剩多少。
代表案例 正常例行付款、一次性付款、計畫外採購、取消釋出、凍結、漲價補差、PDF 待關聯、計費期間待確認。 助理 / 主管 拿來測 MVP 流程、畫面、欄位與狀態規則。 只能做空畫面，無法驗證流程是否正確。
人員與角色 助理、承辦、主管、處長名單與可看 / 可改 / 可確認 / 可送審權限。 主管 建立待辦、權限、責任人與簽核節點。 無法做角色畫面與責任追蹤。
廠商與統編 廠商名稱、統編、付款方式、合約關聯、採購累計、定期支付與專案支付。 助理 建立廠商 / 統編關聯頁與採購累計查詢。 統編、廠商、合約與付款資料無法互相下鑽。

MVP 第一階段開發輸入

這一區收齊後，才適合開始做第一條流程 Code。

可開發 第一條流程
開發項目 需要的資料 完成判斷
Excel 匯入 最新版 Excel、Sheet 清單、欄位名稱、欄位對照、範例資料。 匯入後可看到原始列、Case_ID、來源檔名、匯入批次。
案件清單 案件欄位、狀態、責任人、金額、月份、來源。 可依案名、負責人、月份、金額、狀態篩選。
單案詳情 一筆代表案例的 Excel 原列、PDF、廠商、預算、付款資料。 可從單案看到來源、欄位、文件、狀態與異動紀錄。
主管預算 去年編列今年、今年核定、預算流向、計畫外採購、凍結取消、保留申請。 可看 KPI、預算流向、揭露表、今年 / 去年預計專案。
支出費用 例行性 / 一次性分類、付款期間、核銷月份、上月價格、本次價格。 可看差異、費用類型、本月支出與待確認案件。
每月上簽 每月上簽 Excel、已簽紀錄、簽呈 PDF、簽呈編號。 可選月份，看預計上簽與已簽紀錄。
來源追溯 Excel 原列、PDF 檔、匯入時間、修改紀錄、責任人。 每個金額、廠商、統編、請購編號都能追到來源。
