全文檢索設計

搜尋不是每個頁面的局部篩選，而是系統共用能力。使用者應能用同一個搜尋框查到 Excel 原始欄位、正式案件、合約、廠商、人員、PDF 簽呈內容與來源紀錄。

搜尋框型態

可參考既有系統的全域搜尋列，但搜尋範圍要改成費用合約控管資料。

全域搜尋 權限過濾 PDF 內容
⌕ 搜尋案名 / 合約 / 廠商 / 統編 / 公文編號 / 人員 / PDF 簽呈內容 / Excel 原列
如果業主已習慣「搜尋資產 / Hostname / IP / 人員 / AP」這種搜尋列，費用系統也應提供同等級的全域搜尋。但搜尋結果必須依角色權限過濾，不能因為全文檢索就看到不該看的金額或簽呈。

搜尋範圍

搜尋類別 可搜尋內容 結果應顯示
案件 Case Case_ID、案名、類別、簡述、狀態、Release_Gate 原因。 案件摘要、目前狀態、責任人、下一步。
合約 Contract 合約編號、合約名稱、廠商、統編、合約起迄日、付款方式。 合約摘要、到期日、續約狀態、關聯案件。
費用 / 預算 費用項目名稱、主分類、子分類、預算金額、預算內外、差異說明。 費用項目、預算線、差異與來源。
付款 / 核銷 / 發票 付款年度、月份、金額、期別、核銷編號、發票日期、付款備註。 付款期程、核銷進度、發票狀態。
PDF 簽呈內容 簽呈案號、主旨、廠商、金額、期間、付款條件、決策結論、文字摘錄。 命中頁碼、摘錄文字、關聯 Case、人工確認狀態。
Excel 原始來源 檔名、Sheet、Row No、原欄位、原值、匯入批次。 來源檔、Sheet、Row、欄位名稱、對應後正式資料。
人員 / 組別 承辦人、負責窗口、核銷者、組別、確認人。 人員相關案件、待辦、確認紀錄。
稽核紀錄 建立、修改、退回、作廢、人工確認、回匯套用紀錄。 動作時間、人員、前後值與來源。

資料設計建議

搜尋索引

search_index

建立共用搜尋索引，存 object_type、object_id、title、snippet、keywords、source_type、permission_scope。

PDF 文字

document_texts

PDF 文字依 document_id、page_no、text_content、parse_status 保存，搜尋結果可回到頁碼。

Excel 原值

import_rows / import_cells

原始 Excel 欄位與值要能被搜尋，結果可回到檔名、Sheet、Row、欄位。

權限

permission_scope

搜尋結果必須先套角色權限；處長、主管、承辦、助理看到的結果和金額欄位不一定相同。

業主需要確認

搜尋框提示文字是否採用：案名 / 合約 / 廠商 / 統編 / 公文編號 / 人員 / PDF 簽呈內容 / Excel 原列。
PDF 搜尋結果是否必須顯示頁碼與文字摘錄。
Excel 搜尋結果是否必須顯示檔名、Sheet、Row 與原欄位。
承辦是否能搜尋到其他組別案件，或只看自己 / 本組範圍。
金額、PDF 簽呈、稽核紀錄是否需要依角色遮蔽。

PM 提醒

全文檢索不能只是搜尋畫面上的資料。真正要做的是把 Excel 原始資料、正式資料、PDF 文字、人工確認與稽核紀錄都納入索引，並且每筆結果都能追回來源。否則搜尋會變成漂亮但不可信的入口。
