Excel + PDF Systemization / 欄位盤點

Excel / PDF 欄位盤點與系統化設計

既有 Excel 是目前的業務資料庫，PDF 是簽呈內容與決策依據。第一版系統要先承接既有資料，再做檢核、拆表、流程與 UI 改善。

核心欄位群組

費用主檔

費用項目與廠商

費用項目代碼、費用項目名稱、廠商、統編、標的分類、組別、負責窗口。

合約

合約與期間

合約總金額、合約起日、合約迄日、付款方式、合約狀態、是否跨年度。

預算

預算編列

年度、主分類、子分類、費用名稱、預算金額、資本 / 費用化分類。

付款

付款與期別

付款年度、付款月份、付款金額、計費期間、總期數、已付期數、繳別 / 期別。

核銷

核銷與發票

費用核銷申請日、核銷編號、核銷者、發票形式、發票日期、給付方式。

文件

文件 checklist

費用核銷申請書、付款憑證、請購簽呈、費用分攤表、驗收單、合約書、其他文件。

Excel 欄位到系統模組

Excel 欄位群 系統模組 設計建議
費用項目代碼、費用項目名稱、廠商、統編 cost_items / vendors 作為費用與廠商主檔，不應只存在 Excel row。
合約起日、合約迄日、合約總金額、付款方式 contracts / contract_terms 建立合約資料與到期提醒，支援續約追蹤。
預算年度、預算金額、主分類、子分類 budget_lines 作為 Budget_Check 基準，支援預算內外判斷。
付款年度、付款月份、付款金額、計費期間 payment_schedules / payment_records 拆成付款明細，支援期別、跨年度與月支出預估。
核銷申請日、核銷編號、核銷者、處理進度 expense_claims 建立核銷工作清單，與承辦待辦串接。
發票形式、發票日期、付款備註詳情 invoices 建立發票資料與給付條件，不混在付款備註裡。
文件欄位 document_requirements / documents 轉成文件 checklist 與上傳紀錄。
備註、差異說明 notes / audit_logs 保留原文；若具有固定狀態意義，應再拉正式欄位。

系統化流程

1

匯入 / 上傳暫存

Excel 保留原檔名、Sheet、Row、原欄位；PDF 保留檔名、頁碼與可抽取文字。

2

欄位對應

將 Excel 欄位對應到 Case、Contract、Budget、Payment、Expense、Invoice、Document。

3

系統檢核

檢查必填、格式、重複、金額差異、日期衝突、PDF 與 Excel 是否一致。

4

人工確認

助理或管理者確認欄位 mapping；必要時主管下鑽 PDF 原文與頁碼。

5

全文索引

將 Excel 原值、PDF 文字、正式資料與稽核紀錄納入搜尋索引，並套用角色權限。

6

正式資料與報表

確認後才寫正式資料，Dashboard、報表快照、Excel 回匯都以正式資料為準。

不要做歪的地方

不要把 Excel 丟掉；第一版要能承接 Excel。
不要讓使用者重填 Excel 已經有的欄位。
不要把每張 Excel 都硬做成一個系統頁面。
不要直接用匯入資料覆蓋正式資料。
不要把專案追蹤表強行當費用主檔。
不要把 PDF 當一般附件；它是簽呈依據。
不要只搜正式資料；Excel 原列與 PDF 頁碼也要能被全文檢索找回。
