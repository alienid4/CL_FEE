助理主要作業

新增

新增案件

從上簽清單、發票或續約資訊建立案件，補案名、負責人、金額、月份與來源。

更新

付款狀態

依發票與核銷進度更新付款月份、付款金額、期別與處理狀態。

查詢

合約到期

每週查看續約合約進度，確認是否即將到期、是否需要提醒或補資料。

整理

上簽清單

每月整理次月預計上簽項目，確認案名、類別、金額與說明。

核對

金額差異

核對本月費用與上月費用差異，避免付款或上簽金額錯誤。

追溯

來源查找

用案名、公文編號、負責人、月份與金額找資料來源與歷史紀錄。

最容易錯漏的地方

付款計費期間
期間容易填錯、漏填或與合約期間不一致。第一階段應做格式檢核與合約期間比對。
上月費用差異
金額差異目前需要人工比對。第一階段應至少提示本月 / 上月差異，並保留差異說明。

案名

案件查詢

公文編號

簽呈查詢

全文

全域搜尋

第一階段功能優先順序

優先 功能 理由 保守說法
1 費用項目整合23 資料承接與檢核 收到發票時使用頻率最高，最直接影響付款與核銷。 匯入放管理介面；助理日常使用清單與檢核結果。
2 付款計費期間檢核 目前最容易填錯或漏填。 先做格式與區間提示，由人確認。
3 上月費用差異提示 可降低人工比對錯誤。 先提示差異，不自動判定原因。
4 基本搜尋 目前常用案名、公文編號、負責人、月份、金額查資料。 先搜正式欄位與來源資訊，PDF 全文後續擴充。
5 次月上簽清單與續約進度 分別是每月與每週固定作業。 先形成清單與提醒，不承諾自動簽核。

接下來要確認：建議答案與優缺點

後續問題不空問業主，先提供我方建議，再請業主判斷是否符合實務。

有建議 有取捨 好判斷
問題 我方建議答案 優點 缺點 / 代價 其他選項
付款計費期間要怎麼填？ 建議用起訖日：`計費起日` + `計費迄日`，畫面可顯示為 2026/01/01-2026/01/31。 可精準檢核合約期間、跨月、跨年度與發票期間。 助理需要補完整日期；舊資料若只有月份，需先補值或用月底推估。 只填年月：較簡單，但無法處理跨月或非整月計費。
付款計費期間的正確來源看哪裡？ 建議優先順序：發票 / 帳單 → 合約 → PDF 簽呈 → Excel 既有值。 最貼近實際請款，且能回到原始憑證。 發票或帳單若格式不一致，初期仍需人工確認。 以 Excel 為準：最快，但容易把既有錯誤帶進系統。
上月費用差異要跟誰比？ 建議以「同費用項目 + 同廠商 + 同計費週期」比對。 比單純案名更穩，能避免案名改寫造成比對失準。 需要先把費用項目與廠商資料整理乾淨。 以案名比：容易理解，但案名只要改字就可能比不到。
差異多少要提醒？ 建議第一階段「只要不同就提醒」，但分成低 / 中 / 高差異。 不漏掉異常，適合初期建立信任。 提醒數量可能偏多，助理初期需要多判斷。 設定門檻：較少干擾，但可能漏掉小額卻重要的錯誤。
公文編號能不能當唯一查詢鍵？ 建議不要當唯一鍵，只作為重要查詢條件之一。 可避免尚未上簽、補件、同案多公文時找不到資料。 系統仍需 Case_ID 作主軸，多一層關聯設計。 以公文編號為主：查簽呈方便，但不適合所有案件生命週期。
收到發票後第一步要查什麼？ 建議搜尋順序：廠商 / 費用項目 → 月份 → 金額 → 公文編號或案名。 符合發票作業情境，也能快速找到應付款項。 需要費用項目與廠商名稱先標準化。 先查案名：適合專案型費用，但例行費用常常案名不穩。
