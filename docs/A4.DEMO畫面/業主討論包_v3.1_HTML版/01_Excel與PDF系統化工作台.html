Excel-first Systemization / v2.9

既有 Excel 控管資料如何系統化

這不是全新系統取代 Excel，而是把 `A3.附件` 裡的 Excel 與 PDF 簽呈變成可匯入、可檢核、可追溯、可下鑽、可回匯的系統資料。第一版先承接既有欄位與簽呈內容，再逐步改善流程與 UI。

系統化流程

Excel 先進暫存，不直接覆蓋正式資料。

保留來源 先檢核 人工確認 PDF 不只是附件
1

Excel / PDF 匯入

記錄檔名、Sheet、Row No、PDF 頁碼、匯入人。
2

暫存區

保留原 Excel 欄位，不直接寫正式表。
3

欄位與內容對應

把 Excel 欄位與 PDF 簽呈內容對到 Case、Contract、Payment、Budget。
4

系統檢核

檢查必填、金額、日期、合約、預算內外、PDF 與 Excel 是否一致。
5

人工確認

助理、承辦、主管、處長依角色確認。
6

正式資料

確認後建立 Case、費用項目、合約、付款、核銷、簽呈文件。
7

全文索引

索引案名、合約、廠商、人員、PDF 文字、Excel 原列與稽核紀錄。
8

報表與回匯

產出 Dashboard、報表快照，必要時回匯 Excel。

四角色 UI 要改成 Excel-first

使用者看到的不是「我要重填資料」，而是「系統幫我整理 Excel 後，我只處理例外」。

助理 / 管理者

Excel 匯入與欄位 mapping

L1 匯入批次，L2 Sheet / Row / PDF 清單，L3 單列欄位 mapping 與 PDF 內容比對，L4 原 Excel、PDF 頁碼與修正紀錄。

承辦

補資料與核銷

承辦不重填 Excel 已有欄位，只補缺漏：PDF 簽呈、來源、附件、預算外原因、帳單、發票。

主管

看例外與風險

主管不用看所有 Excel row，只看預算外、合約不明、逾期、跨子公司、金額異常，必要時下鑽 PDF 簽呈。

處長

只看 Release_Gate

處長看整理好的決策包，來源可下鑽到 Excel 原列與 PDF 簽呈頁碼，但不直接面對所有欄位。

要跟業主確認的欄位問題

問題 原因 業主需確認
哪一份 Excel 是正式主檔？ 新舊整合表欄位重疊，不能兩份都當唯一真相。 建議以 `費用項目整合23.xlsx` 為第一版主資料。
費用項目代碼是否可當系統代碼？ 若可當穩定 ID，匯入與回匯會簡單很多。 確認是否唯一、是否會重編。
費用名稱、核銷項目、合約名稱如何比對？ 目前不同表用不同名稱描述同一件事。 確認比對規則與人工勾稽流程。
預算內/外以哪張表為準？ 費用項目主檔與預算編列都出現預算資訊。 確認預算檢核基準。
核銷文件欄位是否都要系統化？ 核銷 sheet 裡有費用核銷申請書、付款憑證、請購簽呈、合約書等文件欄位。 確認第一版哪些文件必填，哪些先保留備註。
PDF 簽呈要解析哪些內容？ PDF 是簽呈依據，不是一般附件。 確認案名、金額、廠商、期間、公文編號、簽核層級是否必須擷取。
專案追蹤表是否只做關聯？ 專案表有大量甘特日期欄，不應直接塞進費用主流程。 確認 Project_ID 成立時才關聯專案進度。
