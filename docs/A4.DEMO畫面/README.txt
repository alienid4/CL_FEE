費用合約控管暨簽呈流程追蹤系統 - 子功能級 HTML 畫面原型

用途：
- 用於第一次/第二次需求會議討論每個子功能畫面。
- 純靜態 HTML，不含後端、不接資料庫、不做 API。
- 所有資料都是示意假資料。

使用方式：
1. 解壓縮 ZIP。
2. 直接用瀏覽器開啟 index.html。
3. 左側選單可切換各角色首頁與每個子功能畫面。

包含畫面：
- 處長 Dashboard、每月預計支出、費用分類摘要、待決策事項
- 主管 Dashboard、每月應上簽、卡關逾期、合約續約、核銷異常
- 助理資料管理工作台、資料更新月曆、Excel 匯入、匯入批次、資料整併、資料品質、金額驗證、Excel 回匯、報表中心
- 承辦待辦、我的案件、狀態更新、文件補件、核銷付款更新
- 費用合約主檔、案件詳情頁、簽呈看板、付款期別、金額變更、歷史比較、附件、異動紀錄
- 角色權限與狀態規則設定

注意：
- 此版本只用於 UI/UX 與需求確認。
- 後續交給 Codex 開發時，請依 README_DEV_Codex.md 與 StructeredPrompt 規範實作。
- 正式開發需拆成 public/index.html、public/css、public/js 等結構，不要把所有程式碼放在單一檔案。
